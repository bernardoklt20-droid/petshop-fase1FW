# PetShop Amigo Animal – Fase 2

## Descrição

Este projeto foi desenvolvido para a disciplina de Fundamentos de Web. O objetivo é criar um sistema web para um petshop, aplicando conceitos de HTML, CSS, Bootstrap e JavaScript.

## Funcionalidades

### Página Inicial

* Apresentação do petshop.
* Carrossel de imagens utilizando Bootstrap.
* Relógio atualizado em tempo real utilizando JavaScript.

### Produtos

* Exibição dos produtos disponíveis para venda.
* Imagens com descrição alternativa (atributo alt) para acessibilidade.

### Serviços

* Informações sobre os serviços oferecidos pelo petshop.
* Valores dos serviços disponíveis.

### Contato

* Informações de telefone, e-mail e endereço.

### Cadastro e Agendamento

* Cadastro de cliente.
* Cadastro do pet.
* Escolha do serviço (banho ou tosa).
* Escolha do método de atendimento (tele-busca ou entrega no local).
* Seleção de data e horário para agendamento.
* Confirmação de agendamento utilizando JavaScript.

## Tecnologias Utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
